Zabbix greenfield installation

1. Checking for updates
sudo apt update && sudo apt upgrade -y

2. Download Zabbix repository package 
sudo wget https://repo.zabbix.com/zabbix/7.4/release/ubuntu/pool/main/z/zabbix-release/zabbix-release_latest_7.4+ubuntu22.04_all.deb


sudo dpkg -i zabbix-release_latest_7.4+ubuntu22.04_all.deb

sudo apt update

3. installing server, frontend, and agent 

sudo apt install zabbix-server-mysql zabbix-frontend-php zabbix-apache-conf zabbix-sql-scripts zabbix-agent

4. Create initial database

sudo mysql -uroot -p
create database zabbix character set utf8mb4 collate utf8mb4_bin;
create user zabbix@localhost identified by '<choose-a-password>';
grant all privileges on zabbix.* to zabbix@localhost;
set global log_bin_trust_function_creators = 1;
quit;

5. On Zabbix server host import initial schema and data. You will be prompted to enter your newly created password.

zcat /usr/share/zabbix/sql-scripts/mysql/server.sql.gz | mysql --default-character-set=utf8mb4 -uzabbix -p Zabbix

password = <the password chosen above>

6. Disable log_bin_trust_function_creators option after importing database schema.

sudo mysql -uroot -p
password
mysql> set global log_bin_trust_function_creators = 0;
mysql> quit;
